# VYRAL

**Don't chase virality. Engineer the opportunity.**

VYRAL is an AI growth co-pilot for short-form creators. The product is designed around one daily loop: discover the highest-potential opportunity, turn it into a content kit, publish at the best window, diagnose performance, and learn.

## Stack

- Next.js + React + TypeScript
- Tailwind CSS
- Lucide React
- Recharts (analytics layer)
- Planned: PostgreSQL/Supabase, Redis, TikTok OAuth/Display API/Content Posting API, AI orchestration, background jobs

## Current build

The first production-oriented frontend foundation includes:

- responsive creator dashboard
- live intelligence status
- opportunity score cards
- Creator DNA
- Trend Radar
- posting recommendation
- performance diagnosis
- mobile navigation shell
- dark creator-first visual system

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.
